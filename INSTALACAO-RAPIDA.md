# 🚀 Instalação Rápida do Node.js

## ⚡ Método Mais Simples (Recomendado)

### **1. Baixar Node.js**

Abra seu navegador e acesse:

👉 **https://nodejs.org/dist/v20.11.0/node-v20.11.0.pkg**

Isso vai baixar o instalador oficial do Node.js para Mac.

### **2. Instalar**

1. Abra o arquivo `.pkg` que foi baixado
2. Siga o assistente de instalação
3. Clique em "Continuar" → "Continuar" → "Instalar"
4. Digite sua senha quando solicitado
5. Aguarde a instalação (1-2 minutos)
6. Clique em "Fechar"

### **3. Verificar Instalação**

Abra um **NOVO Terminal** (importante!) e execute:

```bash
node --version
npm --version
```

Você deve ver:
```
v20.11.0
10.2.4
```

## 🎯 Executar a Aplicação

Depois de instalar o Node.js, execute estes comandos:

```bash
# 1. Navegar até a pasta
cd "/Users/aquillesantonysantiagosantos/Downloads/relatório-de-célula---gestão-semanal"

# 2. Instalar dependências
npm install

# 3. Iniciar servidor
```
